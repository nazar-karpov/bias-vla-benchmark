# Bias Benchmark для VLA-моделей

Бенчмарк для измерения bias (систематических отклонений / предвзятости) у
Vision-Language-Action (VLA) моделей.

> **Статус:** проект только начат (2026-07-25). Цели, тип bias, набор моделей и
> среда прогона будут уточняться по ходу работы — см. журнал ниже.

## Что это

Цель — построить воспроизводимый бенчмарк, который выявляет и количественно
измеряет bias в поведении VLA-моделей. Что именно считать bias, какие модели и
какую среду (симуляция / реальное железо / оффлайн) использовать — определяется
итеративно и фиксируется здесь по мере принятия решений.
